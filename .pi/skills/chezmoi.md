# chezmoi dotfiles

Source tree: `chezmoi/` — `dot_x` maps to `~/.x`, `dot_config/x` maps to `~/.config/x`.
`README.md` is ignored via `.chezmoiignore`.

## Rules

- Edit the SOURCE file under `chezmoi/`, never the home file.
- Apply loop: `chezmoi diff` → `chezmoi apply` → `chezmoi verify`.
- Never commit secrets or git identity. They live per-machine in `[data]`
  of `~/.config/chezmoi/chezmoi.toml` (generated by `setup_chezmoi` in
  `setup/common.sh`, which prompts for them).
- Optional template blocks must be nil-safe, e.g.:
  `{{ if index . "mise" }}{{ if index .mise "deepseek_api_key" }}...{{ end }}{{ end }}`
  (direct `.mise.deepseek_api_key` errors when the key is absent).
- Adopt new files with `chezmoi add ~/.config/foo`.
- `setup/*.sh` end with `chezmoi apply`; keep dotfile handling out of them.
